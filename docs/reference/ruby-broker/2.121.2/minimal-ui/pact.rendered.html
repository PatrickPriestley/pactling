A pact between UiCheckout and UiPayments

Requests from UiCheckout to UiPayments

  • An order lookup given order 42 exists

Interactions

Given order 42 exists, upon receiving an order lookup from UiCheckout, with

{
  "method": "GET",
  "path": "/orders/42"
}

UiPayments will respond with:

{
  "status": 200,
  "body": {
    "id": 42,
    "state": "ready"
  }
}
